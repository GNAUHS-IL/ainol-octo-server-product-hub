# PRD 返工模式：引用目标源码版本落后导致行号越界

## 场景
PRD 草稿引用了目标源码仓行号；Review 方使用更新后的目标源码复核时，发现引用行号超过当前文件范围。

## 风险
- PRD 虽然在草拟者本地通过核验，但远端 Review 失败。
- 越界引用会削弱需求证据可信度，必须返工后重新提交 Review。

## 检查项
1. 引用核验前先同步目标源码只读 clone 到当前 `origin/main`。
2. 对接近文件尾部的引用额外检查目标文件总行数。
3. 引用支撑的产品表述必须与当前源码真实能力一致；缺少证据时写待确认，不硬引旧行号。
4. 返工后重新执行引用核验，并在 issue 评论区回填总数、通过数和失败数。
