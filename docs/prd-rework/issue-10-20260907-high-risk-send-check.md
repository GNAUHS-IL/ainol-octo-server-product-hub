# PRD 返工经验：P0 高风险发送前校验

适用于客户群、外部群、未知归属群、敏感内容、跨对象发送、代用户发送或状态结论类消息的 P0 需求。

## 必查项

- 是否明确客户群 / 外部群 / 未知归属群分级口径。
- 是否明确普通发送者、产品运营负责人、群/Space 管理员、授权复核人的确认边界。
- 是否明确哪些场景必须人工复核，哪些场景可二次确认，哪些场景必须阻断。
- 是否明确敏感内容提示只展示脱敏风险类型，不复述明文 token、cookie、secret、私钥、验证码或客户敏感原文。
- 是否明确状态误报红线：blocked、wontfix、duplicate、invalid、未复现、证据冲突、待确认不得转述为已完成或已修复。
- 是否明确误拦截后的取消、修改后重试、提交人工复核、复核拒绝/超时处理。
- 是否要求上线前演练客户群、外部群、未知群、敏感内容、跨对象发送、代用户发送、状态误报样例。

## 防返工口径

P0 高风险发送需求在无法证明“未确认不发送”、无法限定确认权限、或无法脱敏展示敏感内容时，不应进入 accepted；应保持 Review/返工/阻塞状态，由产品运营负责人最终仲裁。
