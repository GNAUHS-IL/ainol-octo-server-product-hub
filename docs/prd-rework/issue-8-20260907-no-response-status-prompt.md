# PRD 返工经验：Bot 无响应状态提示阈值

适用于“无响应 / 等待中 / 连接异常 / 无权限提示”类 PRD。

## 必查项

- 首次无响应提示阈值必须明确，例如 30 秒内无接收、处理中、失败或完成类反馈即提示。
- 已有处理中状态后的二次提示阈值必须明确，例如 2 分钟无最终结果或下一步提示即再次提示。
- 群内无明确产品运营负责人时，必须给出默认下一步文案，不能保留二选一待确认。
- PRD 内 Labels 检查和引用核验状态必须与实际交接状态一致。
- 等待、失败、无权限、断开、待人工确认不能互相混用。

## 防返工口径

用户可见阈值和下一步文案属于产品规则，不能以“待确认”形式进入 Review；若确需保留配置弹性，也应先给出默认口径和可验收行为。
