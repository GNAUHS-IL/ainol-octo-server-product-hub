# PRD 返工沉淀：Issue #2 Bot/Agent 无响应提示

## 返工时间

2026-09-07T17:48:00+08:00

## Review 打回原因

1. “长时间无响应”的触发阈值未定义，验收时无法判断何时必须提示。
2. “重新连接 / 等待重试 / 联系负责人”的场景边界未定义。
3. 无权限提示里的联系人或处理入口未定义，导致下一步建议不可验收。

## 修复动作

- 将首次无响应提示阈值定义为“30 秒内无任何接收、处理中、失败或完成类提示”。
- 将已有处理中状态后的等待更新定义为“2 分钟内仍无最终结果或下一步提示”。
- 将操作完成、失败或异常后的结果提示保留为“3 秒内用户可见”。
- 明确“继续等待 / 稍后重试 / 重新连接 / 联系产品运营负责人 / 补充信息”的适用边界。
- 明确无权限下一步为“联系本群产品运营负责人或项目负责人确认权限”。
- 补强验收标准，确保每条验收都能用用户可见结果判断。

## 防复发检查项

- PRD 中出现“长时间”“合理时间”“稍后”等表达时，必须定义可验收阈值或明确触发状态。
- PRD 中出现“下一步建议”时，必须写清不同场景分别建议等待、重试、重新连接、联系谁或补充什么。
- PRD 中出现“无权限”时，必须明确用户可执行入口，同时不得泄露无权查看对象或敏感凭证。
