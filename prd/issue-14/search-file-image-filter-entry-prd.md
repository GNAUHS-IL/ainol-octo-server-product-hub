# PRD：搜索增加“只看文件 / 图片视频素材”筛选入口

## 1. 背景与问题

用户反馈：群里图片和文件越来越多，在 Octo 搜索里找素材很麻烦，希望能直接按素材类型筛选，只看文件或图片视频素材。

源码核验显示，后端已经存在独立的文件搜索与图片/视频搜索能力，因此本需求不按“后端从 0 新增搜索能力”处理，而是定义用户可见搜索入口和筛选体验：让用户能在搜索界面明确选择素材类型。本期口径以现有后端能力为边界：文件筛选对应文件类结果，媒体筛选对应图片/视频素材结果；如需“图片-only”，需研发确认是否已有或新增更细粒度过滤能力。

- 文件搜索已有独立入口。来源: modules/messages_search/search_files.go#L57-L64
- 文件搜索会限定文件类消息。来源: modules/messages_search/search_files.go#L162-L167
- 图片/视频搜索已有独立入口。来源: modules/messages_search/search_media.go#L36-L43
- 图片/视频搜索会限定图片和视频类消息。来源: modules/messages_search/search_media.go#L134-L140
- 文件类型枚举已有稳定分类入口，可供搜索筛选展示使用。来源: modules/messages_search/search_file_types.go#L52-L64；来源: modules/messages_search/search_file_types.go#L65-L75

## 2. 目标与非目标

### 目标

- 用户能在搜索界面选择“全部 / 只看文件 / 图片视频素材”，快速缩小素材搜索范围。
- 本期媒体筛选口径为“图片视频素材”；“只看图片”或“只看视频”作为待研发确认 / 后续可做项，不作为本期强验收。
- 文件筛选结果只展示文件类消息或素材。
- 图片视频素材筛选结果只展示图片或视频类消息 / 素材。
- 结果继续遵守当前用户可见范围，不展示无权限、已删除、已撤回或当前不可见消息。
- 空结果、加载失败、分页加载都有明确用户可见反馈。
- 文档或使用说明明确筛选项含义、适用范围和权限边界。

### 非目标

- 不新增搜索安全边界；安全边界继续以后端现有搜索权限和可见性过滤为准。
- 不重做完整搜索 UI。
- 不做语义搜索、向量搜索或复杂高级搜索语法。
- 不做跨产品素材搜索。
- 不做全量聊天记录导出。
- 不改变文件、图片、视频等消息类型的既有后端定义。
- 不承诺本期支持图片-only 或视频-only 精细过滤，除非研发确认现有能力可稳定支持。
- 不把前端筛选作为权限边界。

## 3. 用户故事

### US-01：群成员按文件筛选查找资料
- 角色：作为群成员
- 场景：当群里文件很多，需要找历史文档、表格、压缩包或其他资料
- 诉求：希望在搜索界面一键切换到“只看文件”
- 价值：以便减少无关文字、图片、视频结果干扰
- 来源: modules/messages_search/search_files.go#L57-L64

### US-02：群成员按图片视频素材筛选查找素材
- 角色：作为群成员
- 场景：当群里图片素材很多，需要快速定位某张图片或视频素材
- 诉求：希望在搜索界面一键切换到“图片视频素材”
- 价值：以便快速从图片/视频素材结果中选择目标素材
- 来源: modules/messages_search/search_media.go#L21-L33

### US-03：产品运营或支持确认搜索结果可信
- 角色：作为产品运营或客户支持人员
- 场景：当用户反馈筛选结果缺失或过多
- 诉求：希望筛选项含义、文件类型分类、权限边界和空结果提示清晰可解释
- 价值：以便区分“没有可见结果”“没有对应类型结果”和“权限不可见”
- 来源: modules/messages_search/search_file_types.go#L8-L22

## 4. 功能需求

### F-01-1 搜索类型筛选入口
- 所属故事：US-01、US-02
- 需求描述：搜索界面应提供素材类型筛选入口，至少包含“全部”“只看文件”“图片视频素材”。
- 业务规则：用户切换筛选项后，结果列表只展示对应类型的可见结果；切回“全部”后恢复全部可见搜索结果。
- 边界场景：如果当前入口暂不支持某类筛选，应给出清晰提示，不应静默无响应。
- 来源: modules/messages_search/search_files.go#L57-L64；来源: modules/messages_search/search_media.go#L36-L43

### F-01-2 文件结果展示
- 所属故事：US-01
- 需求描述：选择“只看文件”后，用户只看到文件类消息或素材结果。
- 业务规则：每条文件结果应展示用户可识别的文件名称、发送人、发送时间和所属会话等必要信息。
- 边界场景：文件名称缺失、文件类型未知或无匹配结果时，用户应看到可理解的降级展示或空结果提示。
- 来源: modules/messages_search/search_files.go#L224-L236

### F-01-3 图片视频素材结果展示
- 所属故事：US-02
- 需求描述：选择“图片视频素材”后，用户只看到图片或视频类消息 / 素材结果。
- 业务规则：每条图片/视频素材结果应展示可识别预览、发送人、发送时间等必要信息，便于用户确认素材。
- 边界场景：素材预览不可用时，应有可理解的占位或失败提示，不影响其他可见结果展示。
- 来源: modules/messages_search/search_media.go#L21-L33；来源: modules/messages_search/search_media.go#L181-L188

### F-01-4 文件类型分类说明
- 所属故事：US-01、US-03
- 需求描述：如提供文件分类下钻，应使用稳定、可解释的文件类型分类口径。
- 业务规则：文件分类名称应用户可理解，且与搜索结果实际类型一致。
- 边界场景：未知扩展名或不在分类内的文件，应进入“其他”或明确兜底分类。
- 来源: modules/messages_search/search_file_types.go#L8-L22；来源: modules/messages_search/search_file_types.go#L52-L64；来源: modules/messages_search/search_file_types.go#L65-L75

### F-01-5 权限与可见性不变
- 所属故事：US-01、US-02、US-03
- 需求描述：文件 / 图片筛选不得改变用户原本可搜索、可查看的范围。
- 业务规则：无权限会话、已删除、已撤回、用户当前不可见消息不得因筛选入口出现而展示。
- 边界场景：可见性判断失败时，应按安全方式处理，不应把底层命中直接展示给用户。
- 来源: modules/messages_search/visibility.go#L195-L209；来源: modules/messages_search/visibility.go#L216-L221

### F-01-6 空结果、失败与分页反馈
- 所属故事：US-01、US-02、US-03
- 需求描述：筛选结果为空、加载失败或分页结束时，用户应获得明确反馈。
- 业务规则：空结果应说明当前筛选条件下没有可见结果；加载失败应提示重试或稍后再试。
- 边界场景：切换筛选项、翻页和重新搜索时，结果状态不应混淆或残留旧筛选结果。
- 来源: modules/messages_search/search_files.go#L57-L64；来源: modules/messages_search/search_media.go#L36-L43

## 5. 状态与提示

- 全部：展示当前搜索范围内用户有权查看的全部可搜索结果。
- 只看文件：仅展示文件类可见结果。
- 图片视频素材：仅展示图片或视频类可见结果；不承诺本期区分图片-only / 视频-only。
- 无结果：当前筛选条件下没有可见素材。
- 加载失败：搜索暂不可用，用户可重试或稍后再试。
- 无权限不可见：不展示不可读会话或不可见消息，不暴露目标对象是否存在。

## 6. 验收标准

- AC-01：用户能在搜索界面看到并选择“只看文件”。
- AC-02：用户能在搜索界面看到并选择“图片视频素材”。
- AC-03：用户选择“只看文件”后，结果只展示文件类消息或素材。
- AC-04：用户选择“图片视频素材”后，结果只展示图片或视频类消息 / 素材；不得把现有图片+视频能力验收为图片-only。
- AC-05：用户切回“全部”后，结果恢复为当前搜索范围内的全部可见结果。
- AC-06：文件结果展示文件名称、发送人、发送时间和所属会话等用户可识别信息。
- AC-07：图片/视频素材结果展示可识别预览、发送人、发送时间等信息。
- AC-08：筛选结果仍受当前用户可见范围限制，不展示无权限会话或消息。
- AC-09：已删除、已撤回、当前不可见消息不得出现在文件或图片筛选结果中。
- AC-10：空结果、加载失败、分页加载结束均有明确用户可见反馈。
- AC-11：连续翻页不重复、不丢失当前筛选条件下的可见结果。
- AC-12：如提供文件类型下钻，用户能看到稳定、可理解的分类，未知类型有兜底展示。
- AC-13：文档或说明明确筛选项含义、适用范围、权限边界和失败提示口径。

## 9. 五类风险检查

- 多租户 / Space 隔离：筛选入口不得扩大 Space、群、thread 或 DM 的可见范围。
- 权限 / ownership：用户只能看到当前有权查看的文件和图片结果；前端筛选不是权限边界。
- 安全 / 外部输入 / 凭证：筛选文档和日志示例不得包含 token、cookie、secret 或私钥。
- 限流 / 防滥用：素材筛选不应绕过现有搜索限流和分页约束。
- 审计 / 可追溯：如记录搜索行为，仅记录脱敏条件摘要，不记录明文敏感关键词或不可见内容。
