# [Feature] 希望 Bot/Agent 断联时有用户可见的恢复提示

## 类型

type/feature

## 初始 labels

- type/feature
- priority/P1
- status/prd-drafting
- area/bot-agent
- pm/needs-prd
- source/evaluation

## 使用场景

用户在外部沟通中唤起 Bot/Agent 后，若 Bot/Agent 长时间无响应，需要知道当前是排队、断联、权限不足还是服务异常。

## 用户目标

用户希望在等待或失败时获得明确状态和下一步建议。

## 业务价值

降低交付演示和实际使用中的误判成本，避免用户把无响应误认为需求未被受理。

## PRD 状态

需要 Octo 需求管理专员补充 What-only PRD，不写技术实现。
